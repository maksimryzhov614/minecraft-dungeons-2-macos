Исследование macOS-сборки игры **Minecraft Dungeons 2**: разбор структуры
бинарника, форматов данных, порядка запуска и поведения процесса под
macOS. Работа идёт методами статического и динамического анализа.

**Репозиторий не содержит ассетов игры и не распространяет её файлы.**
Для работ нужна собственная копия игры.

## Статус

- [x] Подготовка среды: ВМ под Parallels для прогоновых тестов (`vm-tune/`)
- [ ] Инвентаризация macOS-сборки: структура `.app`, entitlements, архитектура бинарника

## Окружение

| Компонент   | Значение                                             |
|-------------|------------------------------------------------------|
| Хост        | macOS, Apple Silicon                                  |
| Гипервизор  | Parallels Desktop (`prlctl`)                          |
| Гостевая ОС | Windows 11 (`vm-tune/prep-game.ps1` задаёт опции запуска Steam) |

## Структура

| Путь                            | Назначение                                        |
|---------------------------------|---------------------------------------------------|
| `vm-tune/tune-vm.sh`            | Полный цикл тюнинга ВМ: снапшот → гость → откат   |
| `vm-tune/restore-vm.sh`         | Откат ВМ к снапшоту `pre-tune`                     |
| `vm-tune/tune-guest.ps1`        | Настройка гостя (деблoat, телеметрия, Defender)   |
| `vm-tune/tune-guest2.ps1`       | Второй проход гостевых настроек                   |
| `vm-tune/bench.ps1`             | Замер CPU/RAM в гостевой системе                  |
| `vm-tune/prep-game.ps1`         | Патч `localconfig.vdf`: launch options игры        |
| `vm-tune/backup/`               | Резервные копии конфигов ВМ                        |

## Использование

```bash
# тюнинг ВМ (снапшот делается автоматически)
./vm-tune/tune-vm.sh

# откат к состоянию до тюнинга
./vm-tune/restore-vm.sh
```

## Правила репозитория

- Ассеты, бинарники, дампы памяти и образы ВМ не коммитятся (см. `.gitignore`).
- Каждая настройка ВМ откатывается одной командой (`restore-vm.sh`).
- Находки оформляются заметками с указанием версии и платформы.
